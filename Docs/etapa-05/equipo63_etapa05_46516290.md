## 1. Aporte realizado
Describir brevemente las actividades realizadas durante esta etapa.
- Me encargué de investigar y redactar la teoría sobre el "Manejo de Transacciones". Además, armé el script de SQL con las pruebas para simular una venta que controla el stock, y documenté los casos de éxito y de error para el informe.

## 2. Decisiones en las que participé
Indicar decisiones relacionadas con el dominio, alcance o reglas de negocio.
- Decidimos aplicar la transacción al proceso de ventas. La regla de negocio que establecimos fue que la base de datos debe revisar el stock con un IF/ELSE: si la cantidad que se quiere vender es mayor a lo que hay en la góndola, la venta se cancela por completo y no se guarda nada a medias.

## 3. Problemas o dificultades identificadas
Describir dificultades encontradas durante el desarrollo.
- Al principio me costó bastante y me mareé con la sintaxis del código. No entendía bien el orden en el que iban las instrucciones, ni cómo hacer para probar el código en SQL Server sin tener un programa real conectado. También me confundía en qué momento exacto usar el BEGIN, el COMMIT y el ROLLBACK.

## 4. Soluciones o propuestas realizadas
Explicar brevemente cómo se resolvieron o propusieron resolver las dificultades.
- Lo resolví desarmando el código en pasos más chicos. Usé variables con `DECLARE` para simular los datos que ingresaría un cajero y así poder probarlo. Entendí que el `BEGIN TRANSACTION` va justo antes de hacer los inserts y updates, y que el `ROLLBACK` me salvaba de guardar datos incorrectos si el stock no alcanzaba.
